# 0.2.10（build 17）开发测试候选

本版将语音软件的触发方式与目标键分开。旧配置仍使用 Fn；可改为左右 Command、Control、Option、Shift、F1–F20、空格或 Return。选择软件预设会更新建议模式、保留已选按键；“其他软件 / 自定义”保留当前模式。

## 操作

1. 在目标软件中选择“遥控器麦克风”，设置语音快捷键和点按/长按模式。
2. 在助手的“语音软件”区域选择预设或自定义，将“触发方式”“快捷键”设为同样的值。例如“点按”＋“左 Command”。
3. 保持助手运行，连接麦克风；按住遥控器语音键说话，松开停止。

长按修饰键会影响同期键盘操作；空格和 Return 也可能输入文本或触发发送。是否接受单独修饰键，取决于目标软件。此版不自动替其他软件修改快捷键。

## 已完成的离线验证

- 17 组离线测试共 6,557 项检查通过。其中快捷键与会话测试为 342 项，覆盖旧配置迁移、设置保存/读取、左右修饰键、普通键、权限失败、键释放对象保持、点按前音频缓冲、长按尾音排空和切换时旧键结束。
- 完整应用已编译通过；软件 Fn 保留原有事件构造。音频驱动源码及版本未改。
- 运行完整测试脚本时，安装进程守卫的基线检查检测到旧程序仍在运行，按设计拒绝继续。未关闭用户程序，也未绕过保护；排在其后的独立测试已单独运行并通过。因此不能把整条测试脚本标为全绿。
- 中英文 README、安装说明及验收清单已更新；未改变许可证、系统授权、安装和卸载确认要求。

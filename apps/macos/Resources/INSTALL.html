遥控器助手 · 安装与开始使用

完整安装包同时安装应用、“遥控器按键服务”和“遥控器麦克风”组件，不需要单独下载 BlackHole。固定位置为 /Applications/遥控器助手.app、/Library/PrivilegedHelperTools/OpenRemoteHIDCoreService.app、/Library/Audio/Plug-Ins/HAL/OpenRemoteAudio.driver。安装包不会自行安装；只有你打开 .pkg 并批准后才会写入电脑。

  1. 结束正在进行的会议或录音，运行 0.2.9（build 16）完整安装包。升级前在旧版中按 ⌘Q 完全退出；只关闭窗口并不会退出，系统安装器也会在继续前检查。
  2. 安装不要求重启电脑，也不自动重载音频。完成后退出安装器，打开“应用程序”中的遥控器助手，程序会检测组件是否生效。
  3. 若组件显示已安装但尚未生效，点击重新加载音频服务…。先结束会议、录音和播放，阅读全机音频中断提示，确认并批准管理员授权；也可选择稍后处理。应用会等待专用音频端点就绪，再显示组件已生效。
  4. 在系统蓝牙中配对 RC003-MS（设备自报 RC003），断开其他同类遥控器，然后查找并确认这只设备。
  5. 只用麦克风时无需授权按键映射。在你的录音/会议软件里选择遥控器麦克风，并授予该软件 macOS 麦克风权限。公开输入使用 USB-compatible transport 元数据，以便会排除普通虚拟设备的软件列出它；这不代表实体 USB 连接。如果软件在组件生效前已经打开，请完全退出并重新启动，再检查设备菜单。
  6. 点击“连接遥控器麦克风”，按住遥控器右上角语音键说话，松开停止。
  7. 如需让语音键联动目标软件，在软件自己的输入设备中选择遥控器麦克风，给“遥控器助手”授予辅助功能权限，再从语音软件菜单选择 Typeless、豆包输入法、微信输入法或闪电说对应模式。预设默认关闭；不要求开启顶部完整按键映射，也不需要输入监控、管理员授权或 HID 独占。
  8. 如果目标软件只能跟随系统默认输入，可在助手中明确点击设为系统默认输入并确认；能在设备菜单中直接选择的软件应直接选择“遥控器麦克风”。
  9. 如需在遥控器照片上选键，请为 RC003-MS 重新导入并校准。0.1.x 的旧照片保留在原处，不会自动沿用。

按键映射只检查遥控器助手主程序的输入监控与辅助功能，不再启动或检查“遥控器按键服务”，也不请求管理员密码。主程序只针对已绑定 RC003-MS 尝试独占；macOS 拒绝时共享读取同一设备，并在收到遥控器按键报告后短暂屏蔽对应原系统事件，再发送设置的目标键。

安装、音频服务重载和遥控器连接都不会自动更改默认设备。只有用户明确点击“设为系统默认输入”并确认后，程序才请求改变系统默认输入；它不改默认输出或系统输出，并保存原输入设备的 UID。设置与明确恢复都会等待 CoreAudio 通知并回读结果；如果用户或其他软件后来已经改选输入，程序会清除旧恢复记录。退出不会静默切换默认输入。只有界面已确认“遥控器麦克风”仍是默认输入且存在有效恢复对象时，才会提供“恢复原输入并退出”（默认）、“保留并退出”和“取消退出”；恢复失败时可返回检查或明确保留当前输入并退出。其他状态保持当前默认输入退出。程序不默认登录启动、不录制或上传声音。关闭窗口后可驻留菜单栏；按 ⌘Q 退出会停止所有功能。

当前 0.2.9（build 16）候选仅面向 Apple Silicon / macOS 26 和 RC003-MS（设备自报 RC003，MIOM、硬件 V2.0、固件 2671、软件 A.7.0.6）。用户已确认上一候选的遥控器麦克风进入 Typeless 基本链路可用；新增软件预设、逐键报告和原事件屏蔽仍待实测。

语音软件预设会把已绑定 RC003-MS 所在 LocationID 的全部匹配 HID 服务上的物理 F5 事务式中和为 0，并在每条语音流前重新复核。Typeless 和闪电说“直接说”使用开始、结束各一次短 Fn 点按；豆包输入法、微信输入法和闪电说“帮我说”在按住遥控器语音键期间保持 Fn 按下，尾音排空后释放。普通 Fn 映射与预设使用相同的 macOS 软件 Fn 事件；它不是实体 Globe 键，仍须在目标软件当前版本中验证。

重新加载会暂时中断整台电脑、所有用户的声音和麦克风，包括其他设备的播放、录音及会议。程序不强退其他应用；重载流程不更改默认设备，也不自动恢复遥控器采音。部分软件可能需要完全退出并重新启动，或重新选择输入。

组件缺失时可运行完整安装包；同一产品、结构完整的旧版可直接升级。若固定安装路径的结构或 bundle ID 异常，安装器会拒绝覆盖，请先按它显示的具体错误处理冲突目标。重新加载不能替代安装。授权取消不会撤销已经安装的文件。请求失败、超时或仍未就绪时不会自动重试；保留错误信息，先检查安装和接收软件。整机重启仅作为最后的排查选择，不是安装强制步骤；不要关闭 SIP、Gatekeeper 或删除其他驱动。

0.1.3 修复重载失败后界面一直禁用的问题。系统明确拒绝时恢复普通操作；若显示结果待确认，请点击重新检查并恢复操作。该检查不重载音频、不要求管理员权限，确认本次后台调用已结束后恢复普通功能，同时仍禁止重复发送状态不明的请求。恢复界面不代表麦克风已生效，映射和语音也不会自动开启。

0.1.4 修复按键独占权限缺失和音频插件识别错误。界面分别显示“组件就绪”“遥控器已连接”“已收到音频”：系统能选到麦克风不代表遥控器已连上，仍需点击连接，再按住语音键说话。仅用麦克风无需按键接管的管理员授权。此版本没有修改音频驱动，不需要为识别错误反复重载音频。

0.1.5 针对管理员辅助进程被输入监控拒绝的问题，先把执行文件从随机临时路径移到 root 保护的 /Library/PrivilegedHelperTools/OpenRemoteHIDCoreService.app。后续实测确认，普通权限检查仍作为主程序子进程运行，TCC 会把它归到主程序，因此旧绿勾不能证明按键服务已授权。0.2.2 的 LaunchServices 独立启动才用于重新验证这一归属。

0.2.0 将活动支持范围改为 RC003-MS，使用它自报的 RC003 身份与 ATVV 能力作为连接条件，并隔离新型号的照片与热区校准。已读到能力响应不代表真实语音已到达系统麦克风，也不代表按键已接管。

0.2.1 曾修复 0.2.0 开发包漏带安装脚本归档的问题。0.2.0 在执行 preinstall 前即失败，没有覆盖已安装程序或写入新收据；当前测试请删除旧坏包并使用完整的 0.2.9 安装包。

0.2.2 严格接受 RC003-MS 实机出现的两种能力响应，并在首次连接时等待新的系统音频设备列表，避免使用旧列表误判麦克风不可连接；底层目录查询即使超时，也不会继续无界排队。0.2.3 修复松开语音键时主线程同步等待自己 AudioQueue 回调的死锁，并让安装器在升级前明确要求退出旧版主程序。0.2.4 增加仅由用户明确触发、等待系统确认的默认输入设置与恢复；外部改选后旧恢复记录失效，退出不静默恢复。0.2.5 增加公开输入的 USB transport 枚举兼容、正常松键尾音有界排空，并把界面电平发布限制到 20 Hz。0.2.1 的普通权限 helper 检查实际作为主程序子进程运行，TCC 会把它归到主程序；0.2.2 起改由 LaunchServices 独立启动固定 helper，并只在双向认证套接字内传递单次操作。开发签名下的 helper 同样启用 hardened runtime，且不带放宽动态库注入保护的代码签名权限。当前 ad-hoc 开发包仍必须以实体遥控器验证用户侧 helper 权限与管理员侧真实独占/ready 两个阶段，不能视为生产修复。

0.2.6 统一主程序和管理员音频工具的旧端点识别。工具只在精确的旧版 Virtual/Virtual 双端点或两个产品端点均未注册时允许一次明确授权的重载；当前 USB/Virtual 组合视为已经就绪，任何半残、陌生、身份或通道不符以及查询失败的端点继续拒绝。界面同时区分上次重载操作和当前组件状态。修复后的重载仍须在本机确认成功。

0.2.7 加入默认关闭的 Typeless 成对 Fn 点按兼容。它在开始点按成功前保留句首，松开后排空尾音再结束；中和、点按或复核失败时关闭本次路径，不把声音回落到未启动的 Typeless。代码与离线测试通过不能替代真机验收。

0.2.8 把聚合 pre-roll 分块写入有界 AudioQueue 池，避免第一批音频直接触发“缓冲区已满”；按住录音和连接都不再设置固定时长。按键改用主程序独占或共享读取，不再依赖已失败的独立 helper 授权链。

0.2.9 统一普通 Fn 映射与语音预设的事件路径，并加入点按、长按两类多软件预设。长按模式在开麦前按下 Fn，尾音排空后释放；切换、失败或退出时补做平衡释放。旧 Typeless 开关自动迁移为 Typeless 预设。

当前未纳入 SMAppService：它需要正式签名，包含 LaunchDaemon 的应用还要公证，且已有同类键盘 HID 在 SMAppService root daemon 中仍被 TCC 拒绝的公开案例。面向他人的开源发行必须使用 Developer ID Application / Installer 签名并公证，再实测 SMJobBless/传统 system service XPC 探针或签名公证后的用户 agent 与 root daemon 双角色架构。

在程序内卸载

先停止映射并确认按键辅助进程结束，再从顶部“遥控器”菜单或菜单栏图标选择卸载遥控器助手…。主程序会先停止并退出，独立卸载窗口会继续显示。默认保留个人设置；勾选“同时删除按键方案、设备绑定、照片副本、校准和偏好（含默认输入恢复记录）”才清理当前用户数据；原始照片不会删除。

卸载会从这台电脑移除应用、遥控器按键服务和专用音频驱动，影响本机所有用户使用本程序。只有当前用户的数据可选择清理；勾选后同时清理主程序偏好设置和保存的原默认输入 UID。其他用户的数据、其他音频驱动均不处理。若专用麦克风仍被使用，请先结束相关音频会话；如果它仍是默认输入且存在有效恢复对象，请在退出提示中明确选择“恢复原输入并退出”或“保留并退出”。没有有效恢复对象时程序保持当前默认输入，不在退出时静默切换。

点击开始卸载后由macOS要求管理员授权，不保存密码，不安装后台守护或新的卸载包。系统组件删除并回读成功后，才处理可选个人数据和可识别的旧版卸载临时包。取消、部分失败与成功会分别显示；重启需保存工作后由你操作。

不会取消系统蓝牙配对，不清除权限数据库、系统日志及macOS自行管理的缓存，不承诺系统零痕迹；卸载后系统设置仍可能保留旧版“遥控器按键服务”的权限历史项，可由用户在输入监控列表中移除。下载的安装包和原开发目录需你自行处理。0.2.9 的实际安装、卸载、音频服务重载、RC003-MS 按键共享读取和新增语音软件预设仍需验收。
